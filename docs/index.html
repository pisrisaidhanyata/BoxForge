BoxForge

A Minimal Container Runtime

A C-based educational project exploring Linux container concepts.

View on GitHub

About the Project

BoxForge is a minimal container runtime developed in C on Linux. It demonstrates how operating-system features can create an isolated environment for running a process.

The project is designed for learning and demonstrating container fundamentals. It is not intended to replace production tools such as Docker.

Project Objectives

Process Isolation

Explore Linux PID namespaces and isolated process views.

Filesystem

Run commands using a minimal root filesystem.

Resource Control

Explore cgroups v2 CPU and memory limits.

Linux Concepts

Understand how operating-system mechanisms support containers.

Technologies Used

  • C programming language
  • Ubuntu / Linux and WSL
  • Linux namespaces and root filesystem isolation
  • BusyBox utilities
  • cgroups v2 for resource control
  • Git and GitHub

How to Run

Clone the repository in a suitable Linux environment:

git clone https://github.com/pisrisaidhanyata/BoxForge.git

cd BoxForge

Build the project:

make

Run the container with the required privileges and configuration:

sudo ./boxforge /bin/bash

Follow the repository README for environment requirements and troubleshooting. Required cgroup delegation and Linux features must be available for resource limits to work.
